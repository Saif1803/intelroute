# Code of Conduct

IntelRoute adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and welcoming, assume good faith, give and accept constructive feedback gracefully, and focus on what is best for the project and its users. Harassment, insults, personal attacks, and publishing other people's private information are not acceptable.

It applies in every project space (issues, pull requests, discussions) and when you represent the project in public.

## Reporting

If someone's behavior concerns you, email the maintainer at **saif.dev003@gmail.com**. Reports are kept confidential. The maintainer will review every report and respond with whatever action seems appropriate, following the enforcement guidelines in the Contributor Covenant.
